# Independent register-status review

The frozen `register_status_lemmas_v2` local theorem and generated query graph pass six independent, solver-free artifact tests. The original component contains 506 exact native cells, including all 341 FF bits and the original reset, flush, issue/commit update, and functional-read logic. The local proof assumes only initial reset and the two previously proved native destination-index domains. Its 50 assertions prove 25 six-bit counters and 25 five-bit last-writer tags remain at their native zero reset values. Both single-domain-removal controls have local counterexamples. Those controls are not native full-core traces.

Both certificate-replay outputs equal the frozen decoder/RF certificates. The RD projection has 40 stored-field conclusions and its replayed lowered JSON and SMT match the recorded proof. The actual register-status inputs are issue bits 461–465 and commit bits 466–470. The original source/domain and exact proof model/log hashes are bound in `review.json`.

The produced graph is based on the **cumulative RF candidate** `371a91db...`, yielding `022a6067...`. Independent comparison confirms exactly 50 FF cells are deleted and all 275 corresponding Q input edges, ports, and aliases are replaced by zero. Every other cell property and surviving connection is preserved except those substitutions; no native input changes.

This graph must not replace the current **decoder-only plus inactive-FU** admission model `7406d617...`. In that current model, all 506 register-status cells and the native clock/reset/index bindings are unchanged, and the 275 Q bits are disjoint from all 1,761 already-proved inactive constants. However, ten cells in the RD projection differ from the original source because those proved constants have already been substituted. Every difference matches that exact substitution, and none of the 200 stored RD-field bits is replaced.

Applying the same 275 constants to the current query therefore requires composing the existing source-bound decoder, external ROM, RD-domain, and inactive pointwise-equivalence chains, checking the native component/bindings, and generating a fresh current-graph substitution with its own hash. Direct source-hash substitution or importing the cumulative RF graph would be incorrect. RF-specific demux/predicate wire IDs are irrelevant to this transport. This review found no semantic blocker, but does not emit the new query or serve as a replayed importer certificate.

The review reruns no solver and adds no assumptions. It validates all 269 dependencies of the current prepared native query. The exact artifact tests are `tests/unit/test_register_status_review.py`; they explicitly skip if original workspace artifacts are unavailable. Source hashes, local proof bindings, transport checks, and limits are in `review.json`; `tests.log` records six passes. The 275 bits intersect zero retained FFs in the audited GLA maps, so any proof-speed benefit is still unmeasured.
